# Tools and Libraries

## 1. LangGraph

**Purpose:** Low-level orchestration framework for building stateful, multi-step and multi-agent LLM workflows with persistence, memory, human-in-the-loop control, and graph-based execution.

**Why relevant:** Suitable for implementing explicit debate graphs such as generation -> critique -> rebuttal -> judge -> refinement.

**Official project:** https://github.com/langchain-ai/langgraph

## 2. Microsoft AutoGen

**Purpose:** Framework for building conversational single-agent and multi-agent applications, with AgentChat and Core components.

**Why relevant:** Directly supports research and experimentation with multi-agent collaboration.

**Official documentation:** https://microsoft.github.io/autogen/stable/index.html

## 3. CrewAI

**Purpose:** Framework for designing collaborative AI agents, crews, tasks, flows, memory, knowledge and structured outputs.

**Why relevant:** Useful for constructing role-based scientific research workflows such as researcher, critic, reviewer, ranking, and synthesis agents.

**Official documentation:** https://docs.crewai.com/

## 4. PaperQA2

**Purpose:** Agentic retrieval-augmented generation for scientific documents, with literature search, evidence gathering, metadata handling and citation-grounded answers.

**Why relevant:** Scientific hypothesis systems need reliable literature retrieval and evidence grounding.

**Official project:** https://github.com/Future-House/paper-qa

## 5. OpenAlex

**Purpose:** An open index of scholarly research with APIs and data access for works, authors, institutions, concepts and citations.

**Why relevant:** Useful for discovering, checking and organizing scholarly literature for an AI-for-science research repository.

**Official documentation:** https://docs.openalex.org/
