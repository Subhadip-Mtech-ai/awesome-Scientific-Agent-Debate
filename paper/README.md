## Compile (Overleaf — Recommended)

> [!IMPORTANT]
> `pdflatex` is **not** installed in this local environment.
> Upload the `paper/` folder to [Overleaf](https://overleaf.com) and compile `main.tex`.

1. Upload all `.tex`, `.bib`, and `figures/` to a new Overleaf project.
2. Set the main file to `main.tex`.
3. Click **Recompile** (pdflatex → bibtex → pdflatex × 2).
4. Download the compiled PDF.

## Compile Locally (if LaTeX installed)

```bash
cd paper/
pdflatex main.tex
bibtex main
pdflatex main.tex
pdflatex main.tex
```

## Structure Notes

- `main.tex` uses `\input{body}` and `\input{numbers}` — keep all files in the same directory.
- Table files (`tab_*.tex`) are `\input`-ed from `body.tex`.
- Figures are referenced via `\graphicspath{{figures/}}` — only the basename is needed in `\includegraphics{}`.
- The `\N{...}` macros in `numbers.tex` are generated by `scripts/make_paper_numbers.py` and must be re-run if experimental results change.
