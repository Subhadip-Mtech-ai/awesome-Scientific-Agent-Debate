# GitHub Implementations

## 1. ChatEval

**Repository:** https://github.com/thunlp/ChatEval

**What it implements:** Multi-agent debate for evaluating generated text. Agents with different roles debate and provide judgments.

**Why relevant:** It is a direct implementation connected to a foundational multi-agent debate paper and demonstrates role-based debate and evaluation.

## 2. SciAgents

**Repository:** https://github.com/openags/SciAgents

**What it implements:** An extensible multi-agent framework for scientific research workflows, with LLM agents, tools and support for scientific/robotic workflows.

**Why relevant:** Directly connected to multi-agent scientific discovery and hypothesis generation.

## 3. AI Co-Scientist

**Repository:** https://github.com/The-Swarm-Corporation/AI-CoScientist

**What it implements:** A multi-agent framework inspired by the AI co-scientist methodology, including hypothesis generation, review, ranking, tournament-style evolution and diversity control.

**Why relevant:** Closely matches the scientific hypothesis-generation focus of this repository.

## 4. ML-Multiagent-Debate

**Repository:** https://github.com/shaan-m-patel/ML-Multiagent-Debate

**What it implements:** A practical multi-agent debate implementation with single-response and multi-round debate modes.

**Why relevant:** Useful as a simple educational implementation for understanding how debate differs from a single LLM response.

## 5. Multi-LLM-Debate

**Repository:** https://github.com/tyrionhuu/Multi-LLM-Debate

**What it implements:** Implementation of a multi-LLM debate system with configurable models and adaptive stability detection.

**Why relevant:** Demonstrates practical orchestration of multiple LLM instances and configurable debate rounds.
