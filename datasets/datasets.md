# Datasets

## 1. HypoData

**Source:** HypoArena / Hugging Face

**Description:** A scientific hypothesis-generation benchmark containing research contexts and candidate hypotheses across multiple scientific domains.

**Application:** Useful for comparing single-LLM and multi-agent systems on hypothesis generation and evaluation.

**Link:** https://huggingface.co/datasets/HypoArena/HypoData

## 2. Think Like a Researcher Dataset

**Source:** GitHub repository `mskaa3/think-like-a-researcher`

**Description:** Dataset for LLM-based scientific ideation built from structured literature-derived concept connections, with evaluation data for novelty and grounding.

**Application:** Useful for training or evaluating systems that generate research hypotheses from scientific knowledge.

**Link:** https://github.com/mskaa3/think-like-a-researcher

## 3. SciFact

**Source:** Allen Institute for AI

**Description:** A scientific claim-verification dataset containing expert-written scientific claims paired with evidence-containing abstracts and labels/rationales.

**Application:** Useful for evaluating factuality, evidence retrieval, citation support, and scientific claim verification around AI-generated research outputs.

**Link:** https://github.com/allenai/scifact
