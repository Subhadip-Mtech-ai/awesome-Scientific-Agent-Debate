# Results

This directory contains all experimental outputs. Results are generated by running:

```bash
python scripts/run_all.py --config configs/experiment.yaml
```

## File Index

| File | Description |
|------|-------------|
| `condition_A_outputs.json` | Raw hypothesis outputs for Condition A (SL) |
| `condition_A_scores.json` | Per-prompt scores for Condition A |
| `condition_A_summary.json` | Aggregated metrics + 95% CI for Condition A |
| `condition_B_outputs.json` | Raw hypothesis outputs for Condition B (SC) |
| `condition_B_scores.json` | Per-prompt scores for Condition B |
| `condition_B_summary.json` | Aggregated metrics + 95% CI for Condition B |
| `condition_C_outputs.json` | Raw hypothesis outputs for Condition C (MAD) |
| `condition_C_scores.json` | Per-prompt scores for Condition C |
| `condition_C_summary.json` | Aggregated metrics + 95% CI for Condition C |
| `condition_C_error_analysis.json` | Per-prompt failure mode classification |
| `token_log_A.json` | Per-call token usage log, Condition A |
| `token_log_B.json` | Per-call token usage log, Condition B |
| `token_log_C.json` | Per-call token usage log, Condition C |
